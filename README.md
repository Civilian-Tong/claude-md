# claude-md

个人 Claude Code 工作规范，用于明确 AI 助手在项目协作中的工作方式、执行边界和汇报要求。

## 规范内容

这份规范主要包括：

- **沟通与判断**：先收集现象和证据，再分析原因，最后给出可执行方案。
- **工程原则**：优先采用简单、实用的改动，并兼容现有数据、接口和配置。
- **任务执行**：根据任务规模安排计划、实施和验证；不擅自扩大修改范围。
- **数据库与生产环境**：优先只读检查；涉及状态变更或生产操作时，先明确影响范围和回退方式。
- **Git 管理**：提交前检查工作区和暂存内容，不提交密钥、本地配置或无关文件；未经明确要求不推送。
- **文档与验证**：根据改动范围维护相关文档，并按风险选择适当的验证方式。
- **结果汇报**：说明改了什么、验证了什么、有哪些未完成事项或风险。

## 使用方式

将 `CLAUDE.md` 放在项目根目录，Claude Code 会在该项目中读取这份规范。

不同项目的技术栈和协作要求可能不同，使用前请按项目实际情况调整内容。

## 说明

本文件是个人工作规范，不代表 Anthropic 或 Claude Code 官方规则。
